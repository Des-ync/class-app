# class-app

School and work shuttle service app.

## Features

- Morning trips: pick up registered students and workers from a designated stop or home and drop them at school/work.
- Evening trips: pick them up at agreed times and return them to their stop/home.
- Monthly subscriptions: riders pay a fixed monthly amount.

## Run locally

```bash
npm install
npm start
```

Open http://localhost:3000

## Test

```bash
npm test
```
